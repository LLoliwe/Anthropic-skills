# CLAUDE_HANDOFF_PACK_v1.md

## A) Snapshot Summary
**What it is:** A premium, "black box" engineering console landing page for Pryntor (Pty) Ltd, positioning governance as an operating system.
**Who it is for:** Founders, Ops Leaders, and teams in regulated environments seeking audit-ready automation.
**Primary CTA:** "Request access" (Waitlist mode) / "Request a call" (Contact mode).
**Secondary CTA:** "Email lebo@pryntor.co.za".

## D) Component Inventory

**Button:**
*   Variants: Primary (Solid Cobalt), Secondary (Outline/Ghost), Link.
*   States: Hover (Brightness up), Active (Scale down slightly), Disabled (Opacity 50%).
*   Props: `size` (sm, default, lg), `variant`, `asChild`.

**Card:**
*   Variants: Feature Card (Bordered), Form Card (Solid).
*   States: Hover (Border color change to Primary).
*   Props: `className`.

**Input/Textarea/Select:**
*   Style: Flat, square borders, dark background (`bg-muted/5`).
*   States: Focus (Primary border ring), Error (Red border + inline text).

**Badge:**
*   Style: Monospace, small text, subtle background.
*   Usage: "System Status", Section Kickers.

## E) Form Spec

**Waitlist Form:**
*   `fullName`: Required, min 2 chars.
*   `email`: Required, valid email format.
*   `company`: Required, min 1 char.
*   `role`: Optional.
*   `goal`: Required selection.
*   `notes`: Optional, max 300 chars.
*   `consent`: Required true.
*   **Spam Protection:** Honeypot field (hidden), Rate limiting on submission endpoint.

**Contact Form:**
*   `fullName`: Required, min 2 chars.
*   `email`: Required, valid email format.
*   `company`: Optional.
*   `message`: Required, min 10 chars, max 1000 chars.
*   `capabilities`: Optional boolean.
*   **Spam Protection:** Honeypot field (hidden), Rate limiting on submission endpoint.

**Validation UX:**
*   Inline error messages below fields.
*   Submit button disabled while submitting.
*   Success state replaces form content.

## F) Design Tokens (Brief)

*   **Type Scale:** Inter (Body), JetBrains Mono (Technical labels). Scale: 12px (micro), 14px (small), 16px (body), 18px (large), 24px (h3), 30px (h2), 48-72px (h1).
*   **Spacing Scale:** 4px base unit. 4, 8, 16, 24, 32, 48, 64, 96, 128.
*   **Breakpoints:** sm (640px), md (768px), lg (1024px), xl (1280px).
*   **Radii:** 0px (Sharp/Square) for almost everything to enforce "technical" feel.
*   **Borders:** 1px solid. Default: `oklch(0.3 0 0)`. Active: `oklch(0.6 0.18 250)`.
*   **Shadows:** Minimal to none. Depth created by borders and opacity.
*   **Colors:**
    *   Background: Deep Charcoal (`#050505`)
    *   Text: Off-white (`#E0E0E0`)
    *   Accent: Electric Cobalt (`#3B82F6`)
    *   Border: Subtle Grey (`#333333`)

**Grid & Rhythm:**
*   12-column grid on desktop.
*   Strict vertical rhythm using 8px multiples.
*   "Control lines" (borders) separate major sections.
