# LVL7 Water Lab — original internal R0 interactive science experience

**Runnable self-contained app:** [index.html](index.html) — open locally or preview the HTML in a browser; no account, third-party JS package, paid API, or personal learner data.

A tangible combination of:
- Pryntor original prerequisite DAG library logic (the centrally published engine was independently tested with real source-pinned Marble v1; this standalone export embeds a copy of that original utility).
- An **original authored six-topic demonstration fixture**, NOT Marble's 1,590-topic dataset or licensed authored content. Do not confuse this fixture with exact real Marble graph entries.
- Original deterministic no-loss 100 g water model at 1 atm. Starts as liquid at 20°C; requires 33.44 kJ to reach 100°C and 259.04 kJ total to fully vaporise (from 20°C).
- Original responsive SVG beaker, energy slider, play/pause, visual heating curve, keyboard-friendly controls, reduced-motion preference, original first-consequential-error reasoning check (no automated grading).
- Independent Wolfram Language arithmetic cross-check (33.44, 259.04, -8.36, -41.76 kJ). No live personal data.

**Technical QA**: Local original model/graph 12/12 tests; local Chromium smoke on 1440px desktop, 390px phone and 768px reduced-motion viewport: all interactive cases PASS, no JS page errors and no horizontal overflow. Hosted browser CI on GitHub must pass *on this PR's exact head* before merging.

**Safety**: Idealised no-loss model, not an actual heated physical experiment, not a child-safety instruction, real steam dynamics or a physics laboratory certification. Requires educator review and age/standards/localisation before product release. Show Your Working’s teacher grading engine is NOT imported; only an original feedback teaching pattern is used.
