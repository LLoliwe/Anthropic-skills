## Three derived original directions
A. **Quiet Operator**: all-white, whisper serif and small state pill; best for agent conversation, lower brand energy.
B. **Editorial Voltage**: art-directed ink/ivory with citrine/lime focal object; single active question, authored type and restrained motion. **Selected** as distinctive Pryntor product direction.
C. **Evidence Archive**: black archival grid with project poster tiles; strong for reference browsing, less direct for reviewing a release.

## Implementation acceptance
- Product work done in actual Void Node application, not a picture; no stock images or copied layouts
- No generic KPI card row or utilitarian fixed sidebar; show one release decision at a time
- Responsive 360/390/768/1440 and reduced-motion support
- Accessible focus, form labelling, keyboard, touch targets and no horizontal overflow
- Preserve six gates, state persistence, evidence notes, example, clear/reset, JSON export, and API status. Clear distinction between self-report and independent approval
- Keep data browser-local. No new tracking, APIs, invoices or customer data
- Run built Node HTTP tests, browser interaction QA, and screenshot review before releasing
- Keep Render Free and manual deployment. Independent security signoff and reliability still HOLD.

## Rejection criteria
No more stock SaaS template feel, empty metric tiles, invented real-world evidence, clone of Frida/Sol/HyperFrames, arbitrary complex 3D, scrolling gimmicks, confusing multi-step mobile inputs or false production readiness.
