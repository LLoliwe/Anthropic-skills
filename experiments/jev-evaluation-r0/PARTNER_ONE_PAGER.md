## Specific 60-day proposal

We ask for a **complimentary no-card, hard-capped pilot**, with:
1. A small first tranche of Jev input tokens and written expiry and use limits. Optional expansion only after technical milestones. We can discuss a larger ceiling if warranted, not demand a large grant up front.
2. Named API or developer-relations contact and version guidance for Jev stable and preview.
3. Written confirmation of zero automatic paid conversion/refill; supported South African legal entity and applicable access region.
4. Processing, retention and telemetry terms suitable for synthetic-only proof, with a separate future privacy/security review for real data.

In exchange, we can supply a private **reproducible evaluation report** for three bounded cases:
- Next approved diagnostic selection after an agent fails source-matched acceptance criteria;
- Research/partnership lead triage into internal draft and human-review queues;
- Creative QA findings routed to domain specialists (safety, rights and accessibility).

We will pre-register task distribution, hard safety gates and blinded external labels before vendor evaluation. Compare against deterministic rules and existing approved model paths. Report macro-F1 and class-level precision/recall, abstention and error calibration, p50/p95/p99 latency, cost per *correctly safely completed task*, and all false-approval counterexamples. Avoid reverse engineering, model extraction, vendor-output training and unapproved security probing. Public case studies require mutual written approval.
